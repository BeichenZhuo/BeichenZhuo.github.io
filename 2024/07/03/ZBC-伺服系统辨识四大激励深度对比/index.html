对比四种系统激励方式：正弦定点、Chirp扫频、PRBS伪随机、锤击法

发表于2024-07-03|更新于2026-07-03
|浏览量:

前言

做伺服带宽测试、谐振辨识、系统建模、控制器参数整定，绕不开四种经典激励方式：单频定点正弦、Chirp线性扫频、PRBS伪随机序列、锤击脉冲法。

很多工程开发者最大的核心困惑，也是行业最易混淆的知识点：

  • 为什么正弦扫频必须等待稳态，不能直接采瞬态数据？

  • Chirp到底属于稳态辨识还是瞬态辨识？真实频谱形态是什么样？

  • PRBS与锤击法都是宽频激励，二者底层原理的本质差异在哪里？

  • 工程上到底什么时候用直接FFT、什么时候用互相关？Welch平均法的核心作用与适用场景？

一、扫频方式原理分类

1. 稳态遍历型（正弦、慢速Chirp）

依靠正弦相干确定性激励，逐频点获取系统稳态增益与相位，信号相干性极强、信噪比高，是高精度系统建模的核心方案。

核心本质：依靠信号自身相干性抑制噪声，无需统计平均，单周期数据即可实现高精度辨识。

2. 宽带统计型（PRBS、锤击）

一次性全频段覆盖激励，依靠时域统计相关性或系统瞬态冲激响应求解频响特性，适配工业复杂噪声环境。

核心本质：依靠多周期统计平均、互相关运算压制不相关随机噪声，牺牲计算速度换取辨识鲁棒性。

二、四种激励逐一深度解析

1. 单频定点正弦扫频（标准稳态辨识金标准）

本质：纯稳态响应辨识

每次仅输入单一固定频率正弦信号，伺服系统会经历短暂瞬态振荡过程，必须等待瞬态分量完全衰减、输出变为稳定等幅同相振荡后，方可采集数据。瞬态数据包含零输入响应、暂态误差，无法表征系统真实频域特性。

频谱特性：单根离散谱线，带宽极窄、能量高度集中，无多余频率分量。

数据处理方式：直接 FFT 求解频响函数 $H(f)=\dfrac{Y(f)}{U(f)}$。

核心特点：

  • 幅频、相频精度最高，谐振峰、相位滞后辨识最精准，是工业Bode图标定金标准；

  • 完全规避瞬态误差，可直接用于陷波滤波器设计、伺服带宽标定、控制器参数精准整定；

  • 测试效率极低，需要逐频点等待稳态，耗时最长。

适用场景：产品出厂标定、学术实验、高精度建模、机械谐振精准定位与参数校准。

2. Chirp线性扫频（连续变频正弦）

核心定位：既非纯瞬态辨识，也非白噪声辨识

本质：串行连续准稳态遍历辨识

Chirp 是单频率时序依次遍历带宽，并非所有频率同时激励系统，和PRBS并行激励逻辑完全相反。

慢扫Chirp（工程推荐）：满足扫频速率约束 $k \ll \dfrac{B^2}{Q}$（$B$为系统带宽，$Q$为阻尼系数），频率变化远慢于系统过渡过程，每个瞬时频率均可近似达到稳态，等价于无数个正弦稳态扫频无缝拼接。

快扫Chirp：前一频率瞬态响应未完全衰减，后一频率即刻接入，输出为多频率瞬态叠加响应，会造成频响失真、谐振峰抹平、辨识带宽偏小。

频谱特性说明

线性Chirp为工程默认使用类型，带宽内幅频特性近似均匀平坦，仅时域截断处存在轻微吉布斯纹波，频谱平坦度优于PRBS；对数Chirp低频扫速快、高频扫速慢，高频停留时间更长，会出现高频能量占比偏高的现象。

Chirp数据算法适配规则

Chirp数学上完全支持互相关、Welch算法处理，不存在算法不兼容、引入额外误差的问题。常规高信噪比场景下，直接 $H=Y/U$ 计算精准、执行效率更高；工业强噪声场景（电流干扰、编码器抖动）中，对Chirp采用分段互功率谱Welch平均法，可有效压制不相关随机噪声，仅牺牲少量计算速度，无精度损失。

适用场景：现场快速调试、产线批量测试、中等精度Bode图快速获取、替代低效的定点正弦扫频。

3. PRBS伪随机序列

本质：准白噪声、全频段并行激励、统计降噪辨识

与Chirp串行遍历逻辑完全相反，PRBS所有频率分量同时并行激励系统，依靠统计特性实现宽频辨识。

频谱特性

PRBS并非全频段绝对平坦，作为二值电平序列，其功率谱密度严格遵循 $\mathrm{sinc}^2$ 包络：

$S_{uu}(f) \propto \mathrm{sinc}^2(\pi f T_c) = \left(\dfrac{\sin(\pi f T_c)}{\pi f T_c}\right)^2$

其中 $T_c$ 为PRBS码元时钟周期，$f_c=1/T_c$ 为时钟频率。

整体频谱特性：低频段（$f \ll f_c$）近似平坦，满足常规辨识需求；高频段衰减明显，在 $f=f_c/3$ 处幅度滚降约 -3.9dB；工程有效辨识带宽仅为 $f_c/5 \sim f_c/3$，超高频段需加逆sinc补偿滤波器修正频谱畸变。

PRBS强制使用相关类算法的核心原理

伺服系统存在大量与激励无关的加性随机噪声，包括电流噪声、编码器量化误差、摩擦扰动、负载波动等，直接FFT无法滤除干扰。基于维纳-辛钦定理，可通过H1频响估计公式彻底剥离噪声，提取纯净系统响应：

$H(f) = \dfrac{S{uy}(f)}{S{uu}(f)}$

式中 $S{uy}(f)$ 为输入输出互功率谱，仅保留与激励相关的系统响应分量；$S{uu}(f)$ 为输入自功率谱，表征激励自身频谱特性。随机噪声与PRBS激励不相关，经互相关运算后噪声分量统计平均趋近于0，仅保留线性系统真实响应。

PRBS序列长度选取原则

序列长度需兼顾低频辨识精度与系统LTI特性稳定性，禁止过短或过长：总时长必须满足 $T \ge 1/f_{\mathrm{low}}$，保证低频分辨率 $\Delta f=1/T$，避免低频特性失真；同时禁止过长时长激励，防止温度漂移、摩擦时变、积分位置偏移破坏线性时不变系统假设。系统时变较弱时，采集3~5个完整周期做频域平均，可完美兼顾低频精度与降噪效果，周期数量大于10时极易引入系统时变误差，需严格规避。

适用场景：工业强噪声现场、小信号无扰动辨识、伺服在线自整定、自动化系统建模。

4. 锤击法（脉冲激励）

本质：纯瞬态响应辨识，无任何稳态过程

瞬时脉冲近似理想冲激信号，一次性激发系统全频段自由振荡，全程无稳态等待过程。脉冲有效带宽由脉冲宽度决定：$f_{\mathrm{max}} \approx 1/(\pi \tau)$，$\tau$ 为脉冲宽度。

线性系统中，锤击响应近似系统核心动态响应 $y(t)=h(t)$，直接对瞬态响应波形做FFT变换即可得到系统频响特性。

核心优缺点

  • 优势：测试速度最快，单次采集即可完成全频段激励，操作简单高效；

  • 劣势：瞬时冲击能量极大，易激发机械非线性、饱和失真；低频激励能量弱、信噪比极差，是四种辨识方式中伺服建模精度最低的方案。

适用场景：机械结构模态初测、粗略谐振频率摸底，不适合伺服高精度建模与带宽标定。

三、频域计算方法深度拆解

时域数据采集完成后，频响函数（FRF）的计算算法直接决定Bode图精度与可靠性。工程主流三类核心算法：直接FFT法、H1互相关功率谱法、Welch平均法，本节完整拆解算法原理、全套数学公式、优缺点与专属适用场景。

1. 直接复频响法（FFT直接相除）

核心公式

$U(f) = \mathcal{F}{u(t)},\quad Y(f) = \mathcal{F}{y(t)}$

$H(f) = \dfrac{Y(f)}{U(f)}$

算法原理：对输入、输出时域信号直接做傅里叶变换，提取各频点复数幅值与相位，通过复数相除求解每一个频点的系统增益与相位滞后，算法默认输入输出信号完全相干、无随机噪声干扰。

优缺点

  • 优点：运算量最小、实时性最强、无算法固有畸变，高信噪比下精度优异；

  • 缺点：完全无降噪能力，输出端所有不相关噪声、扰动都会直接计入频响结果，导致曲线毛刺严重、谐振特征模糊。

专属适用场景：定点正弦、慢速线性Chirp等高信噪比确定性信号辨识。

2. H1估计法（自/互相关功率谱法）

核心原理：基于维纳-辛钦定理，时域相关函数与频域功率谱为傅里叶变换对，利用随机噪声与激励信号互不相关的统计特性，彻底滤除噪声干扰、提取纯净系统频响。

全套完整公式

离散信号自相关、互相关计算：

$R{uu}[k] = \dfrac{1}{N}\sum{n=0}^{N-1} u[n]u[n+k]$

$R{uy}[k] = \dfrac{1}{N}\sum{n=0}^{N-1} u[n]y[n+k]$

相关函数经傅里叶变换得到对应功率谱：

$S{uu}(f) = \mathcal{F}{R{uu}[k]}$

$S{uy}(f) = \mathcal{F}{R{uy}[k]}$

最终频响函数（H1估计）：

$H1(f) = \dfrac{S{uy}(f)}{S_{uu}(f)}$

降噪逻辑：设输出含噪声信号 $y(t)=h(t)*u(t)+v(t)$，其中 $v(t)$ 为随机加性噪声，$v(t)$ 与输入 $u(t)$ 完全不相关，互相关运算后 $R_{uv}\to0$，可彻底剥离噪声分量，仅保留系统线性响应。

优缺点

  • 优点：抗噪能力极强，可有效压制工业现场各类随机扰动，辨识结果稳定性大幅提升；

  • 缺点：需要多周期完整数据保证统计稳定性，计算量大于直接FFT算法。

专属适用场景：PRBS辨识标配算法、强噪声环境下的Chirp信号处理。

3. Welch平均法（工程终极最优算法）

核心定位：H1相关法的工程增强优化版，是专业辨识设备的底层默认算法。

算法完整步骤+全套公式

  1. 长序列重叠分段：将完整时域数据拆分为多段短序列，段间默认50%重叠，弥补加窗操作带来的信号信息损失；

  2. 加窗抑制泄漏：每段数据叠加汉宁窗 $w[n]$，大幅抑制傅里叶变换的频谱泄漏问题；

  3. 逐段谱计算：对每一段加窗后的输入、输出数据，分别计算单段自功率谱 $S{uu,i}(f)$、互功率谱 $S{uy,i}(f)$；

  4. 集总平均降噪：对所有分段功率谱结果做算术平均，降低统计方差、平滑噪声毛刺。

$\bar{S}{uu}(f) = \dfrac{1}{M}\sum{i=1}^M S_{uu,i}(f)$

$\bar{S}{uy}(f) = \dfrac{1}{M}\sum{i=1}^M S_{uy,i}(f)$

最终频响函数：

$H{\mathrm{Welch}}(f) = \dfrac{\bar{S}{uy}(f)}{\bar{S}_{uu}(f)}$

核心优势：同时解决频谱泄漏、随机噪声干扰、统计方差过大三大工程问题，输出频响曲线平滑、鲁棒性极强，适配绝大多数工业辨识场景。

优缺点

  • 优点：全场景通用、降噪能力最强、曲线无毛刺、辨识稳定性最高；

  • 缺点：计算量为三类算法中最大，低频分辨率受单段数据长度限制。

适用场景：兼容所有激励方式，是工业高精度辨识、量产标定、学术研究的首选算法。

三类算法选型一句话总结

  • 干净实验室环境、快速趋势预览 → 直接FFT（速度最优）

  • 工业噪声环境、PRBS专属辨识 → H1相关法（经典标配）

  • 高精度建模、极致曲线平滑度需求 → Welch平均法（业界最优）

五、核心易错结论总结

1. Chirp 与 PRBS 底层机理完全异构

PRBS 依托全频率同时并行激励+统计平均降噪，频谱存在天然sinc²高频滚降，高频辨识精度受限；线性Chirp依托单频率时序排队遍历+正弦相干降噪，频谱均匀平坦，在无噪声环境下辨识精度更优。二者虽均为宽频辨识方案，但激励逻辑、频谱特性、降噪原理完全不同。

2. 相关类算法为通用降噪方案，并非PRBS专属

PRBS信号无固定稳态波形，必须依赖H1相关法、Welch法滤除噪声，否则有效信号会被噪声淹没；正弦、Chirp确定性信号默认使用直接FFT即可满足常规精度需求，但在强干扰工业现场，切换为Welch平均法可显著提升曲线稳定性，无精度副作用。

3. Welch法是工程辨识终极最优解

Welch法整合了重叠分段、加窗防泄漏、多段集总平均三大核心优化，是H1相关法的工程落地增强版，兼容四种所有激励信号，兼顾降噪能力与频谱精度，是工业设备、高精度建模的标准化算法。

六、场景选择

  • 高精度标定、论文实验、滤波器设计 → 定点正弦 + 直接FFT

  • 工业噪声大、小信号辨识、自动整定 → PRBS + Welch平均法

  • 产线批量测试、效率精度兼顾 → 慢速线性Chirp + 直接FFT

  • 算力充足、追求极致平滑稳定曲线 → 任意激励 + Welch法

  • 机械结构粗略模态摸底 → 锤击法 + 直接FFT
